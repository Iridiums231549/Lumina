Lumina 博客系统使用说明

1. 运行环境
- 建议使用 Python 3.11 及以上版本
- 首次运行前需要安装依赖

2. 安装依赖
在项目目录中打开终端，执行：
python -m pip install -r requirements.txt

3. 启动项目
方法一：
双击“启动网站.bat”

方法二：
在项目目录终端中执行：
python app.py

4. 打开网站
启动成功后，在浏览器访问：
http://127.0.0.1:5000
或
http://localhost:5000

注意：
不要直接双击 templates 文件夹里的 html 文件。
本项目使用 Flask + Jinja 模板，必须通过后端服务运行后再访问网址。

5. 默认账号
管理员账号：
用户名：admin
密码：admin123

普通演示账号：
用户名：editor
密码：editor123

6. 管理员功能入口
使用管理员账号登录后，点击右上角用户菜单，可进入“后台管理”。
后台支持：
- 文章管理
- 用户管理
- 评论治理
- 分类管理
- 公告中心
- 审计日志

7. 分享给组员
如果只是把项目文件发给组员，他们需要在自己的电脑上按上面的步骤运行后才能打开。
如果想让别人直接通过一个网址访问，需要把项目部署到服务器或云平台上。
