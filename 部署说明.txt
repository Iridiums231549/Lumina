Lumina 博客系统部署说明

一、当前可用的两种分享方式

1. 临时公网地址
- 适合课程验收、组员演示、短期分享
- 通过 Cloudflare Tunnel 把本地 5000 端口映射成公网网址
- 优点：不需要改动业务代码，几分钟就能拿到链接
- 缺点：你的电脑必须保持开机，并且本地服务必须一直运行；链接通常是临时的
- 当前这次会话已成功生成过一个可访问的临时公网地址，但它不是永久地址，后续重启通道后通常会变化

2. 正式云部署
- 适合长期访问、后续扩展和正式交付
- 当前项目已补充 Render 部署配置文件 render.yaml
- 优点：可以拿到长期网址，组员随时可访问
- 缺点：需要你们自己的云平台账号；当前项目数据库使用 SQLite，若后续多人长期使用，建议升级到 PostgreSQL/MySQL

二、Render 正式部署步骤

1. 把整个项目上传到 GitHub 仓库
2. 登录 Render
3. 选择 New + -> Blueprint
4. 连接 GitHub 仓库
5. Render 会自动识别 render.yaml
6. 点击部署，等待服务构建完成
7. 构建成功后即可获得在线网址

三、数据库说明

当前项目使用 SQLite。
对于课程演示和小范围访问没有问题，但如果后续扩大适用范围，建议迁移到 PostgreSQL 或 MySQL。
原因：
- SQLite 更适合单机轻量应用
- 多人并发写入时扩展性有限
- 换成服务型数据库后更适合长期上线

已提供脚本：

脚本作用：

- 自动打开 Cloudflare Tunnel
- 在日志中输出临时公网网址

相关日志位置：
- instance\\cloudflared_err.log
